# AppLab — Criador visual de aplicativos

Plataforma educativa para criar aplicativos interativos sem escrever código. Funciona no navegador com HTML, CSS e JavaScript.

## Recursos da versão 1
- Criar projetos vazios ou começar com modelos de **lista de tarefas** e **quiz**.
- Adicionar textos, botões, campos, imagens, cartões, listas, marcações e seletores.
- Criar múltiplas telas, alterar cores, textos e ordenar componentes.
- Configurar botões de forma visual: navegar para outra tela, mostrar mensagem, guardar ou limpar texto e adicionar itens a uma lista.
- Testar as ações no simulador de celular.
- Salvar projetos neste navegador, importar/exportar cópias JSON e desfazer alterações.

## Como começar
Abra o arquivo `index.html` em um navegador. Para hospedar no GitHub Pages, acesse **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**, depois **main** e **/(root)**, e salve.

Clique em **Lista de tarefas** para experimentar um exemplo pronto. No editor, escolha itens à esquerda, visualize ao centro e altere textos e ações à direita. Clique em **Testar aplicativo** para experimentar os botões.

## Limitações importantes
É uma versão inicial de aplicativos web simulados, não um compilador de APKs ou equivalente a um sistema nativo completo. O armazenamento dos **projetos** usa localStorage no navegador; os dados inseridos durante o **teste** são temporários. Não existem contas de alunos, sincronização em nuvem, banco de dados remoto ou publicação individual dos aplicativos nesta versão. Em PCs compartilhados, exporte o projeto em JSON antes de sair e evite usar dados reais/sensíveis de alunos.
